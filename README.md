# Dupe Dupe

Private, invite-only web app that finds new dupes and secondhand matches for higher-end clothes.

- `PLAN.md`: the build plan
- `CLAUDE.md`: rules and current phase for Claude Code
- `prototype.html`: look and behavior reference
- `docs/SETUP-GUIDE.md`: which tools the app uses, how they connect, and step-by-step setup for a new app

Run locally: `npm install`, then `npm run dev`, and open http://localhost:3000.
